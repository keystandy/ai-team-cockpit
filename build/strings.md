# 一、术语表

| 采用词 | 禁用词 | 理由 |
|---|---|---|
| 发布任务 | 下发任务 / 创建任务 / 发起任务 / 提交任务 | 老板方框只有一个主动作，统一叫“发布任务”。 |
| 派活 | 分配 / 分派 / 调度 / 派发 / 下发 | 小棒把任务拆给成员，用产品内统一口语“派活”。 |
| 接活 | 接单 / 认领 / 领取 / 接受任务 | 成员收到并开始处理，用“接活”，和“派活”对应。 |
| 交结果 | 提交 / 交付 / 完成上报 / 回传 | 成员把处理结果交回，动作用“交结果”，不用泛化的“提交”。 |
| 等待中 | 待处理 / 待开始 / 排队中 / 未开始 | 任务已发布但还没开始，状态统一为“等待中”。 |
| 进行中 | 处理中 / 执行中 / 工作中 / 运行中 | 任务正在处理，统一为“进行中”。 |
| 已完成 | 完成 / 成功 / 已结束 / 已交付 | 任务正常结束，状态用“已完成”。 |
| 失败 | 异常 / 出错 / 未成功 / 中断 | 任务没做成，用“失败”；具体原因放在提示里。 |
| 在线 | 空闲 / 可用 / 正常 / 在线上 | 成员已连接、可接活。 |
| 忙碌 | 工作中 / 处理中 / 占用 / 勿扰 | 成员正在处理任务。 |
| 离线 | 下线 / 断开 / 不可用 / 未在线 | 成员连接断开或退出。 |
| 派活单 | 任务列表 / 工单 / 分配清单 / 任务单 | 右栏展示小棒分给成员的具体活，统一叫“派活单”。 |
| 实时事件 | 动态 / 消息 / 日志 / 流水 | 右栏展示团队正在发生的事，统一叫“实时事件”。 |
| 成员详情 | 成员信息 / 人员卡片 / 个人资料 / 详情面板 | 查看单个成员状态和当前任务，统一叫“成员详情”。 |
| 同步时间 | 更新时间 / 最近刷新 / 最后同步 / 数据时间 | 顶栏显示当前页面数据更新到的时间。 |
| 刷新 | 重新加载 / 同步 / 更新 / 拉取 | 顶栏按钮动作，短且明确。 |
