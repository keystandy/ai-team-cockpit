## 路径推算写法

绝对路径由页面自身的 `location.pathname` 推算，没有写死盘符：

```js
function projectRootPath() {
  const p = decodeURIComponent(location.pathname);
  return p.replace(/\/[^/]*$/, "").replace(/^\//, "");
}

function absoluteArtifactPath(relativePath) {
  const root = projectRootPath();
  return root.replace(/\//g, "\\") + "\\" + String(relativePath || "").replace(/\//g, "\\");
}
```

复制优先调用 `navigator.clipboard.writeText(abs)`；异常或不可用时降级到临时 textarea + `document.execCommand("copy")`。
