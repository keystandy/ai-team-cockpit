## 功能要求（这一条是本次的核心，别做成装饰）

现在的旧版是**假派活**：四路同时发光只是动画，实际只给一个人出了一张派活单。这次要改成**真多派**：

- 老板发一句话 → 小棒拆成 **2～4 个子任务**（底线是「执行 + 复核」两路，不能只派一个人）
- 每个子任务独立指派成员，独立走一遍「派活 → 接活 → 交活」
- 右栏的派活单要**同时列出多张**，每张有自己的成员、子任务、命令、状态
- 实时事件流里，每个成员的接活/交活各占一行，按时间顺序滚动
- 任一子任务失败，派活单上那一张标红、事件流里出一条失败事件，其它子任务不受影响

子任务怎么拆：按语义关键词拆（「写/改/实现」→ 执行一路，「审/检查/校对」→ 复核一路，「查/最新/联网」→ 检索一路）。拆不出来就默认「执行 + 复核」两路。**不要用随机数硬凑人数。**
