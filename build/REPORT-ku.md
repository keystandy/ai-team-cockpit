## 3. 五项自测

测试环境：本机 Microsoft Edge，`file://` 直接打开，Playwright 浏览器上下文设为离线。

1. **断网打开：通过。**

   离线上下文加载成功，标题为「AI 团队驾驶舱」，四个员工卡和全部 SVG logo 正常渲染。浏览器事件记录为 0 个控制台错误、0 个页面异常、0 个失败请求、0 张破图。请求仅有页面本身、`assets/logos.js`、`data/office.js` 三个本地 `file://` 资源，无任何远程请求。

2. **1280 / 1440 / 1920 连线对齐：通过。**

   三个宽度逐条测量 `老板 → 小棒` 和 `小棒 → 四名员工` 共 5 条连线，端点与目标卡片边框中心的横纵误差均为 `0px`，小于 `4px` 上限。三档宽度均无横向溢出，右栏实测宽 `320px`，主区与右栏并排。

3. **1024 以下窄屏：通过。**

   实测 `1023px`、`1000px`、`767px`、`375px`：右栏均在主区下方，间距 `32px`，流程图与右栏无重叠；页面横向溢出均为 `0`。员工卡在 `1023px` / `1000px` 为两列，在 `767px` / `375px` 为一列；窄屏连线端点误差仍为 `0px`。

4. **发布按钮五连点：通过。**

   输入「写实现并检查」后同步触发 5 次点击，首次点击后按钮立即显示「发布中」并锁定。最终只有 2 张派活单（小酷执行、小克复核），只有 1 条「收到任务」事件、2 条派活事件、2 条接活事件、2 条交结果事件。全部完成后按钮恢复「发布任务」且可再次点击，没有重复派活或卡死。

5. **键盘与回车：通过。**

   从输入框按 Tab 可依次到达四个快捷短语、清空按钮和发布任务按钮；发布按钮获得焦点时实测焦点环为 `2px solid rgb(37, 99, 235)`、外偏移 `2px`。使用「写一版实现说明，检查并校对，再联网查最新资料」在输入框直接按 Enter，正确生成小酷执行、小克复核、小豆检索三张派活单，三路分别完成并各产生接活/交结果事件。

补充核心验证：输入「写实现并检查，模拟失败」后生成 2 张派活单，其中执行单为失败、复核单为已完成；仅 1 张派活单标红、1 条失败事件、1 条失败连线，另一路不受影响。失败单具备「重试」「改派」操作，恢复完成后仍保留失败历史原因。
